# Open Send — نظام مشاركة الملفات للمدارس عبر الشبكة المحلية

**Open Send** منصة مشاركة ملفات خاصة للطلاب تعمل بالكامل داخل شبكة المدرسة المحلية (LAN)
بدون أي اعتماد على خدمات سحابية: بدون Firebase، بدون Supabase، بدون قواعد بيانات خارجية،
وبدون إنترنت بعد التثبيت.

- جهاز واحد يشغّل السيرفر، وكل الطلاب يتصلون به عبر المتصفح: `http://<server-ip>` (بدون بورت — السيرفر على البورت 80)
- الطالب يسجّل، يختار صفّه، يبحث عن زميل، يرسل ملفاً — ولا يُتاح التنزيل إلا بعد **قبول المستلم**
- لوحة إدارة مخفية على `/webadmin` بمصادقة مستقلة تماماً عن حسابات الطلاب
- ثيم أبيض/أسود مع وضع ليلي، وواجهة **عربية RTL كاملة** بخط ثمانية

## 1. المميزات

### للطلاب
| الميزة | الوصف |
|---|---|
| التسجيل والدخول | اسم مستخدم + كلمة مرور (بدون بريد)، مع اختيار الصف |
| البحث عن الطلاب | بالاسم أو اسم المستخدم مع تصفية حسب الصف |
| إرسال الملفات | سحب وإفلات أو اختيار، ملفات متعددة، رسالة اختيارية، وشريط تقدّم |
| القبول قبل التنزيل | المستلم يقبل أو يرفض أولاً — لا يوجد رابط تنزيل يعمل قبل القبول |
| إلغاء المرسل | إلغاء التحويل وهو معلّق |
| الإشعارات الداخلية | ملف جديد، قبول، رفض، انتهاء — بعدّاد غير المقروء |
| تتبع التنزيلات | عدد التنزيلات، أول وآخر تنزيل |
| انتهاء الصلاحية | تلقائي حسب إعدادات الإدارة |
| الملف الشخصي | تعديل الاسم المعروض وتغيير كلمة المرور |

### للإدارة (`/webadmin` — مخفية، بدون أي رابط في واجهة الطلاب)
- نظرة عامة بإحصائيات حقيقية (الطلاب، الصفوف، تحويلات اليوم، المعلّقة، التخزين)
- إدارة الطلاب: إنشاء، تعديل، حذف، تصفير كلمة المرور، تعطيل/تفعيل، **استيراد CSV جماعي**
- إدارة الصفوف: إنشاء، إعادة تسمية، تفعيل/تعطيل، حذف آمن مع نقل الطلاب لصف آخر
- إدارة التحويلات: بحث وتصفية (مرسل/مستلم/صف/حالة/تاريخ/نوع ملف)، إلغاء، إنهاء، حذف
- لوحة التخزين ببيانات حقيقية من القرص + تنظيف يدوي
- كل الإعدادات (الأحجام، الامتدادات، الانتهاء، قيود الصفوف، الصيانة...)
- سجل تدقيق (Audit Log) قابل للتصفية، ومعلومات النظام والشبكة مع QR
- نسخ احتياطي واستعادة مع نسخة أمان تلقائية قبل الاستعادة

## 2. التقنيات

| الطبقة | التقنية |
|---|---|
| الواجهة | Next.js 14 (App Router) + React 18 + TypeScript |
| قاعدة البيانات | SQLite عبر `node:sqlite` المدمجة في Node — ملف واحد `data/opensend.db` (WAL) |
| تخزين الملفات | قرص محلي `storage/` — لا تُخزّن الملفات داخل قاعدة البيانات أبداً |
| كلمات المرور | `scrypt` (مقوّاة بالذاكرة، مع ملح عشوائي) — لا نصوص صريحة إطلاقاً |
| الجلسات | رموز عشوائية في كوكيز `HttpOnly` + `SameSite=Lax`، تُحفظ مهشّة في الخادم |
| الأيقونات | `lucide-react` فقط — لا إيموجي في الواجهة |
| رمز QR | يُولّد محلياً (`qrcode`) — بدون أي خدمة خارجية |
| الخط العربي | خط ثمانية (ملفات محلية) مع بديل مضمّن يعمل دون إنترنت |

> **لماذا `node:sqlite` وليس Prisma؟** صفر اعتماديات أصلية (native) — تعمل على Windows مباشرة
> بدون Visual Studio أو تحميل محركات خارجية، وتفي بمتطلب "SQLite محلية بدون سحابة".

## 3. متطلبات التشغيل

- **جهاز السيرفر:** Windows (أو أي نظام يشغّل Node) + **Node.js 22 أو أحدث** (يُستخدم 24)
- **الشبكة:** واي فاي/خيط مشترك بين السيرفر والأجهزة (راوتر المدرسة العادي يكفي)
- **المساحة:** حسب حجم الملفات المتبادلة + قاعدة البيانات (كيلوبايتات عادةً)
- **إنترنت:** لازم **مرة واحدة فقط** للتثبيت (`npm install` + `npm run build`)، وبعدها كل شيء يعمل على الشبكة المحلية بدون إنترنت

## 4. التثبيت والتشغيل

```bat
npm install
npm run build
npm run start
```

أو ببساطة شغّل `start-lan.bat` (يثبّت ويبني ويشغّل تلقائياً).

السيرفر يرتبط على `0.0.0.0:80` — أي أنه يستقبل من كل الشبكة المحلية، وليس من نفس الجهاز فقط،
والرابط نظيف بدون بورت (وضع التطوير `dev` يستخدم `:3000`).

| العنوان | الاستخدام |
|---|---|
| `http://<server-ip>` | واجهة الطلاب (مثلاً `http://192.168.100.169`) |
| `http://<server-ip>/webadmin` | لوحة الإدارة — **تُكتب يدوياً، لا يوجد لها رابط** |

> إذا كان البورت 80 مشغولاً ببرنامج آخر: `npm run start:3000` (والرابط يصبح `http://<server-ip>:3000`).

### بيانات الدخول الافتراضية (تُنشأ عند أول تشغيل)

| الحساب | اسم المستخدم | كلمة المرور |
|---|---|---|
| الإدارة | `admin` | `Admin123!` |

> **تنبيه:** غيّر كلمة مرور الإدارة فوراً بعد أول دخول: `/webadmin` ← النظام ← تغيير كلمة مرور الإدارة.

### سكربتات npm

| الأمر | الوظيفة |
|---|---|
| `npm run dev` | وضع التطوير على `:3000` (يرتبط بالشبكة أيضاً) |
| `npm run build` | بناء نسخة الإنتاج |
| `npm run start` / `start:lan` | تشغيل الإنتاج على `0.0.0.0:80` (بدون بورت في الرابط) |
| `npm run start:3000` | بديل الإنتاج على `:3000` إذا كان 80 مشغولاً |

## 5. فتح الموقع من الجوال (أجهزة الشبكة)

1. على السيرفر افتح `cmd` واكتب `ipconfig` — خذ عنوان **Wi-Fi** (مثلاً `192.168.100.169).
   تجاهل عناوين `192.168.56.x` (VirtualBox) وVMware — الجوال لا يصلها.
2. افتح قاعدة جدار الحماية (PowerShell **كمسؤول**) — البورت 80 بدل 3000 الآن:
   ```powershell
   New-NetFirewallRule -DisplayName "Open Send (TCP 80)" -Direction Inbound -Protocol TCP -LocalPort 80 -Action Allow -Profile Private
   ```
   وتأكد أن شبكة الواي فاي مضبوطة **Private** لا Public.
3. الجوال على **نفس الواي فاي**، بيانات الجوال والـ VPN مطفأة، وافتح:
   `http://192.168.100.169` (لاحظ `http` وليس `https`، وبدون أي بورت).
4. أسهل طريقة للطلاب: امسح رمز QR من `/webadmin` ← النظام (اختر رابط الواي فاي من القائمة).

### اسم محلي بدون أي إعدادات: `http://opensend.local`

`start-lan.bat` يشغّل تلقائياً خدمة mDNS صغيرة (`scripts/mdns.mjs`) تعلن عن الاسم
`opensend.local` في الشبكة — بلا سيرفر DNS، بلا راوتر، بلا تعديل أجهزة.
iPhone يفهمه مباشرة، وأندرويد 12+ وWindows كذلك. يلزم فقط قاعدة جدار حماية واحدة
(PowerShell كمسؤول، مرة واحدة):

```powershell
New-NetFirewallRule -DisplayName "mDNS (UDP 5353)" -Direction Inbound -Protocol UDP -LocalPort 5353 -Action Allow -Profile Private
```

ثم افتح من أي جهاز: `http://opensend.local` (البورت 80، فلا بورت في الرابط).
ملاحظة: أندرويد أقدم من 12 قد لا يحل أسماء `.local` — استخدم عنوان IP مباشرة لتلك الأجهزة.

### اسم مخصص لكل الشبكة: `http://open-send.btec` (يحتاج سيرفر DNS)

أسماء مثل `.btec` لا تعمل بتقنية mDNS — تحتاج سيرفر DNS حقيقي على البورت 53.
الخيارات بالترتيب:

1. **Technitium DNS Server (موصى به إن كان مثبّتاً):** يملك البورت 53 تلقائياً.
   افتح `http://localhost:5380` ← Zones ← Add ← Primary Zone باسم `open-send.btec`
   ثم أضف سجل A فارغ الاسم بقيمة عنوان الواي فاي (مثلاً `192.168.100.169`).
2. **Acrylic DNS Proxy (خفيف، ملف واحد):** ثبّته من https://mayakron.altervista.org
   ثم شغّل `scripts\acrylic-setup.bat` كمسؤول — يوقف Technitium (لتحرير البورت 53)،
   ويربط Acrylic بكل الواجهات، ويسمح لشبكتك، ويضيف `open-send.btec`، ويفتح جدار الحماية، ويختبر.
3. **السيرفر المدمج في المشروع (`scripts/dns.mjs`):** بديل بلا تثبيت —
   يعمل فقط إذا كان البورت 53 حرّاً (أي بدون Technitium/Acrylic). شغّله يدوياً بـ
   `node scripts/dns.mjs` — يجيب عن `open-send.btec` ويمرّر باقي المواقع للإنترنت.

في الحالتين: باقي الأجهزة يجب أن **تستخدم هذا البيسي كـ DNS** (مرة واحدة من الراوتر عبر DHCP،
أو يدوياً في كل جهاز)، مع قاعدتي جدار الحماية UDP+TCP للبورت 53. ثم يعمل
`http://open-send.btec` من كل الأجهزة.

## 6. دليل الطالب

```
تسجيل (اسم مستخدم + كلمة مرور + الاسم + الصف)
   ↓
الرئيسية: إحصائيات (معلّقة / مرسلة / مستلمة)
   ↓
إرسال: ابحث عن زميل ← اختره ← أرفق ملفات ← رسالة اختيارية ← إرسال
   ↓
المستلم يرى: "أحمد يريد إرسال ملفات إليك" ← [قبول] / [رفض]
   ↓
بعد القبول فقط يظهر زر التنزيل
```

- **المستلمة:** تبويبات معلّقة / مقبولة / مرفوضة / منتهية / منزّلة / ملغاة.
- **المرسلة:** المستلم + الملف + التاريخ + الحالة، مع إمكانية إلغاء المعلّق.
- حالات التحويل الست: `PENDING` `ACCEPTED` `DECLINED` `EXPIRED` `DOWNLOADED` `CANCELLED` —
  تظهر بأيقونة ونص وشكل مميز (لا باللون وحده).

## 7. دليل الإدارة (/webadmin)

| التبويب | ما يمكنك فعله |
|---|---|
| نظرة عامة | إحصائيات حية: الطلاب، الصفوف، التحويلات، تحويلات/ملفات اليوم، المعلّقة، التخزين |
| الطلاب | بحث + تصفية، إنشاء، تعديل (الاسم/الصف/التفعيل)، حذف، تصفير كلمة المرور، **استيراد CSV** |
| الصفوف | إنشاء، إعادة تسمية، تفعيل/تعطيل، حذف آمن (ينقل الطلاب لصف آخر بدل حذفهم) |
| التحويلات | كل التحويلات مع فلاتر، عرض الملفات (بيانات وصفية فقط)، إلغاء، إنهاء، حذف |
| التخزين | المستخدم/المتاح/عدد الملفات من القرص الحقيقي + زر التنظيف |
| الإعدادات | كل ما في قسم 8 أدناه |
| السجلات | فلترة حسب الإجراء/المستخدم/التاريخ |
| النظام | حالة السيرفر، الشبكة + QR، النسخ الاحتياطي، تغيير كلمة الإدارة |

### استيراد الطلاب CSV

```csv
username,password,name,class
ahmad123,temp123,أحمد خالد,Grade 10 - A
khaled22,temp456,خالد علي,Grade 10 - B
```

- تُشفّر كلمات المرور أثناء الاستيراد ولا تُعرض بعده أبداً.
- الصفوف الافتراضية المزروعة: `Grade 10 - A/B/C`، `Grade 11 - A/B/C`، `Grade 12 - A/B` (قابلة للتعديل الكامل).

## 8. الإعدادات

كل القيم تُدار من `/webadmin` ← الإعدادات وتُطبَّق **في الخادم** (قيود الواجهة للراحة فقط):

| المفتاح | المعنى | الافتراضي |
|---|---|---|
| `registrationEnabled` | السماح بتسجيل الطلاب | `true` |
| `maintenanceMode` | وضع الصيانة (يحجب الطلاب، والإدارة تبقى) | `false` |
| `allowClassChange` | السماح للطالب بتغيير صفّه | `false` |
| `maxFileSizeMB` | أقصى حجم ملف | `50` |
| `maxFilesPerTransfer` | أقصى ملفات للتحويل الواحد | `5` |
| `allowedExtensions` | امتدادات مسموحة (فارغ = الكل) | فارغ |
| `blockedExtensions` | امتدادات محظورة | `exe,bat,cmd,com,scr,msi,ps1,vbs,jar,apk,reg,dll,sys` |
| `defaultExpiryHours` | انتهاء التحويلات (`0` = أبداً) | `168` (7 أيام) |
| `allowMultipleDownloads` | تنزيلات متعددة | `true` |
| `maxDownloads` | سقف التنزيلات (`0` = غير محدود) | `0` |
| `sendScope` | `anyone` / `same-class` / `selected` | `anyone` |
| `classRestrictions` | خريطة JSON: صف المرسل ← الصفوف المسموحة | `{}` |
| `retentionDeclinedDays` / `Cancelled` / `Expired` / `Completed` | مدد الاحتفاظ قبل حذف الملفات | `7` / `7` / `3` / `30` |
| `autoDeleteExpired` | حذف المنتهية تلقائياً | `true` |
| `adminCanPreview` | معاينة الإدارة للمحتوى (مغلقة للخصوصية) | `false` |

## 9. قاعدة البيانات

ملف واحد: `data/opensend.db` (مع فهارس على `username` و`classId` و`senderId` و`recipientId`
و`status` و`createdAt` لسرعة البحث).

| الجدول | المحتوى |
|---|---|
| `users` | الطلاب (الهاش فقط، لا كلمات صريحة) |
| `classes` | الصفوف (تُدار من الإدارة، ليست ثابتة) |
| `admins` | حسابات الإدارة (مصادقة منفصلة) |
| `sessions` | الجلسات (الرموز مهشّة، بانتهاء صلاحية) |
| `transfers` | التحويلات مع الحالة والانتهاء وعدّادات التنزيل |
| `transfer_files` | بيانات الملفات الوصفية (الأسماء الأصلية + المعرفات الداخلية) |
| `notifications` | إشعارات داخلية بلا خدمات خارجية |
| `audit_logs` | سجل التدقيق (لا تُسجَّل كلمات المرور أبداً) |
| `system_settings` | كل إعدادات الإدارة (مفتاح/قيمة) |

## 10. التخزين ودورة حياة الملف

```
storage/
├── pending/     ← بانتظار قبول المستلم
├── accepted/    ← مقبولة وجاهزة للتنزيل
├── completed/   ← نُزّلت (وضع التنزيل الواحد)
├── rejected/    ← مرفوضة / ملغاة / منتهية
└── tmp/
```

- الملفات تُحفظ **بمعرفات داخلية عشوائية** — اسم الملف الأصلي لا يُستخدم كمسار أبداً
  (حماية من Path Traversal وأسماء Windows المحجوزة والتنفيذ التلقائي).
- لا يوجد وصول مباشر للملفات — كل تنزيل يمر عبر API يتحقق من:
  `مصادَق + هو المستلم + الحالة مقبولة + غير منتهٍ + الملف موجود`.
- التنظيف التلقائي يحذف ملفات القديم/المرفوض/الملغي/المنتهي حسب مدد الاحتفاظ.

## 11. مرجع API

### الطلاب (كوكي `opensend_session`)

| الطريقة | المسار | الوصف |
|---|---|---|
| POST | `/api/auth/register` | تسجيل (يحترم `registrationEnabled`) |
| POST | `/api/auth/login` | دخول (محدّد المعدل: 10 محاولات / 5 دقائق) |
| POST | `/api/auth/logout` | خروج |
| GET | `/api/auth/me` | بياناتي + حالة الصيانة |
| PATCH | `/api/auth/profile` | تعديل الاسم (وتغيير الصف إن سُمح) |
| POST | `/api/auth/change-password` | تغيير كلمة المرور |
| GET | `/api/classes` | الصفوف المفعّلة (للتسجيل والتصفية) |
| GET | `/api/students/search?q=&classId=` | بحث الطلاب (بدون بيانات حساسة) |
| POST | `/api/transfers/send` | إرسال (multipart: `recipientId` + `message` + `files`) |
| GET | `/api/transfers/mine?type=sent\|received&status=` | تحويلاتي |
| GET | `/api/transfers/[id]` | تفاصيل التحويل |
| POST | `/api/transfers/[id]/accept` | قبول (المستلم فقط) |
| POST | `/api/transfers/[id]/decline` | رفض (المستلم فقط) |
| POST | `/api/transfers/[id]/cancel` | إلغاء (المرسل، وهو معلّق فقط) |
| GET | `/api/files/[fileId]/download` | تنزيل (بعد القبول فقط) |
| GET | `/api/notifications` + `/unread-count` | الإشعارات |
| POST | `/api/notifications/read-all`, `/[id]/read` | تعليم كمقروء |
| GET | `/api/settings/public` | الإعدادات العامة للواجهة |
| GET | `/api/health` | نبض السيرفر |

### الإدارة (كوكي `opensend_admin` — مصادقة منفصلة، كل مسار يتحقق في الخادم)

## 12. الأمان

- تجزئة `scrypt` + ملح، جلسات مهشّة تنتهي (7 أيام للطالب، 24 ساعة للإدارة)
- تحديد معدل الدخول، `HttpOnly` + `SameSite=Lax`، انتهاء الجلسات
- كل صلاحية تُفحص **في الخادم**: القبول/الرفض/الإلغاء/التنزيل/الإدارة
- التنزيل `attachment` + `nosniff`، بلا URLs قابلة للتخمين، بلا تنفيذ للملفات
- تحقق من الامتدادات والأحجام والعدد ونطاق الصفوف قبل كتابة أي بايت
- حماية XSS (لا حقن HTML)، وحماية SQL Injection عبر استعلامات مُقيّدة
- سجل تدقيق لكل الأحداث المهمة — و`/webadmin` محمية بالمصادقة لا بالإخفاء
  (الإخفاء طبقة إضافية فقط)

## 13. النسخ الاحتياطي والاستعادة

من `/webadmin` ← النظام:

- **إنشاء نسخة:** نسخة من قاعدة SQLite + ملف وصف (بدون كلمات مرور) + خيار تضمين الملفات المخزنة (قد تكون كبيرة).
- **الاستعادة:** تتحقق من أن الملف قاعدة Open Send سليمة، **وتنسخ البيانات الحالية احتياطياً تلقائياً أولاً**، ثم تستبدل.
- **التنزيل:** أي نسخة قابلة للتنزيل من المتصفح.

## 14. اللغة والخط والثيم

- **العربية هي الافتراضية** (RTL كامل: التنقل والنماذج والجداول والإشعارات) واسم الموقع يبقى `Open Send` باللاتينية.
- مفتاح English/العربية في الشريط العلوي، والاختيار يُحفظ محلياً.
- **خط ثمانية:** انسخ ملفات الخط المرخّصة إلى `public/fonts/` بهذه الأسماء واعد التشغيل:
  `Thamaniya-Regular.woff2` و `Thamaniya-Bold.woff2`
  (بدونها يُستخدم خط عربي بديل مضمّن يعمل دون إنترنت).
- **الوضع الليلي:** زر القمر/الشمس بجانب زر اللغة — ثيم دارك أحادي متناسق، ويُحفظ اختيارك.

## 15. استكشاف الأخطاء (FAQ)

| المشكلة | الحل |
|---|---|
| الجوال لا يفتح الموقع | استخدم عنوان **Wi-Fi** (تجاهل VirtualBox) + قاعدة جدار الحماية للبورت 80 + شبكة Private + نفس الواي فاي + `http` بدون بورت (راجع قسم 5) |
| نسيت كلمة الإدارة | لا توجد استعادة ذاتية — أوقف السيرفر، احذف صف الإدارة من `data/opensend.db`، وسيُعاد إنشاء `admin / Admin123!` عند التشغيل |
| التسجيل مغلق | فعّل `registrationEnabled` من الإعدادات، أو أنشئ الحسابات عبر استيراد CSV |
| `This file has expired` | انتهت مدة التحويل — عدّل `defaultExpiryHours` للتحويلات القادمة |
| التنزيل لا يعمل بعد القبول | تأكد من `allowMultipleDownloads` / `maxDownloads`، وأن الملف لم يُحذف بالتنظيف |
| الموقع بطيء على الهواتف القديمة | طبيعي مع القوائم الكبيرة — استخدم البحث والتصفية لتقليل العناصر |
| عزل الأجهزة في الراوتر | بعض راوترات المدارس تفعّل AP/Client Isolation — عطّلها ليسمح للأجهزة برؤية بعضها |

## 18. حدود معروفة

- خادم واحد — لا تعدد خوادم ولا مزامنة (مقصود: مدرسة واحدة، جهاز واحد).
- تحديد المعدل في الذاكرة (يُصفَّر بإعادة التشغيل) — كافٍ لشبكة مدرسية.
- كتابة SQLite متزامنة — مناسبة لمئات المستخدمين المتزامنين، ليست لآلاف.
- عنوان QR الافتراضي أول عنوان شبكة — اختر عنوان الواي فاي يدوياً من القائمة.
- خطوط البديل تُحمَّل **أثناء البناء فقط** (تحتاج إنترنت لمرة واحدة) ثم تعمل دون إنترنت للأبد.
